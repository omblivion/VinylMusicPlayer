# Needle Music Player 0.0.2 — Pre-release di test

**Versione sperimentale per test, non stabile e non pronta per un uso senza precauzioni.**

Questa build è incentrata sulla **reattività della ricerca**. Non introduce nuove funzionalità di prodotto e **non significa che tutti i problemi precedenti o tutto il backlog siano stati risolti**.

## Cosa cambia
- La ricerca non ricostruisce più l'intera libreria a ogni carattere: usa uno snapshot precalcolato e riutilizzabile.
- Le query superate mentre digiti vengono scartate, quindi i risultati vecchi non possono più comparire sotto il nuovo testo.
- Stato "ricerca in corso" distinto da "nessun risultato"; testo vuoto o solo spazi svuota subito i risultati.
- Corretto il caso in cui la ricerca restava vuota dopo aver perso e ripristinato il permesso audio: la query digitata viene conservata.
- Strumentazione dei tempi **solo in build debug** e **senza contenuti** (nessun testo cercato, titolo, artista o percorso registrato).

## APK disponibili
- **`needle-0.0.2-release.apk`**: build release ottimizzata, firmata con la chiave dedicata a Needle. Identificativo `org.needlemusicplayer.android`.
- **`needle-0.0.2-debug.apk`**: build debuggabile per prove, raccolta log tramite adb e diagnosi. Identificativo `org.needlemusicplayer.android.debug`; sull'app compare **Needle DEBUG**.
- **`SHA256SUMS.txt`**: impronte SHA-256 dei due APK per verificarne l'integrità.

Release, debug e Vinyl possono convivere, ma **impostazioni, database e playlist non sono condivisi**. I file musicali sul telefono rimangono invece gli stessi: modificarne i tag o cancellarli può avere effetti anche sugli altri lettori. Non viene eseguita un'importazione automatica da Vinyl.

## Verifiche eseguite
- **47 test JVM/Robolectric superati** e compilazione debug/lint senza nuovi problemi.
- Prove sull'emulatore **Android 17 / API 37** con copie reali di MP3 e fixture sintetiche: categorie titolo/artista/album corrette, sostituzione della query senza risultati obsoleti, svuotamento immediato, Indietro, rotazione con ripristino della query, revoca/ripristino del permesso audio, nessun crash.
- Test automatici su metadati sintetici con **3.736 voci** per scala e correttezza.

## Limiti e backlog aperto
- **L'obiettivo di latenza (p95 dei risultati visibili ≤500 ms) non è ancora misurato sul telefono**: la strumentazione è pronta, la sessione controllata deve ancora essere autorizzata ed eseguita.
- Il **miglioramento dell'indicizzazione** (scansione incrementale e scritture al database raggruppate) è previsto in una fase successiva e **non è incluso** in questa release.
- Restano aperti: migrazione a Media3, componenti asincroni/UI obsoleti, copertura completa di formati, schede SD, Bluetooth, Android Auto, modifica tag e cancellazione.
- Alcuni testi tradotti e dettagli grafici conservano ancora parte del branding storico.

**Prima di testare, conserva una copia dei file musicali importanti.** Non pubblicare log senza controllare e rimuovere percorsi, nomi di file o altri dati personali.
